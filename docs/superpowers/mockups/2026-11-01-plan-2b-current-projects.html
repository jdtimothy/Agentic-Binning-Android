Plan 2b · Task 6A · Nov 1, 2026

Current projects: open, create, remove

The project sheet's list becomes Current projects: the projects loaded into the app. Two buttons, Open project and New project, sit under the heading. Edit puts a small × on each row; tapping × takes the project off the list and never deletes its database or files. Each phone is live: try Edit, ×, Undo and Done.

Owner's direction (Nov 1): the two buttons, Edit with ×, the name "Current projects", and no long explanations in the UI. Points marked Open are proposals for the owner.

STATE 1

The project sheet

  • The open project's block keeps 2a's Add a folder and Pick photos and clips. Its label changes from "Current project" to Now open, so it doesn't read like the list heading below (Open, P7a).
  • Current projects lists every project in the app, the open one first with an Open pill. Tap a row to switch.
  • Open project opens the system folder picker; New project opens 2a's New project page.
  • A project whose folder is gone shows Folder missing; it can still be removed.

STATE 2

Edit: a small × on each project

  • Edit turns into Done. Rows show × in place of the chevron and don't switch projects.
  • Open project and New project hide while editing, so the only action is removing.
  • × takes the project off the list at once. Its media, folders, database and thumbnails stay where they are; Open project brings it back.
  • Edit is disabled while media is being added or a project is being created.

STATE 3

Removed, with Undo

  • A short toast, "Removed Sort Test", with Undo for a mis-tap on a small target. It puts the row back where it was (Open, P7b).
  • No dialog for a project that isn't working: nothing is lost, and Open project brings it back after the toast is gone.
  • Removing the open project when nothing runs works the same way, then the next project in the list opens.

STATE 4

Removing the open project while it analyzes

  • The only confirmation: × on a project with analysis or sorting running asks "Stop analysis and remove Hawaii Photos?" (Open, P7c).
  • Remove stops the run (the model is released), takes the project off the list and opens the next project, Maui here.

STATE 5

No projects

  • On first launch, after a reinstall, or after removing the last project, the sheet shows the same two buttons over an empty list (Open, P7d). Today 2a opens straight on the New project form, which hides Open project from someone reinstalling.
  • No Edit while the list is empty.

STATE 6

Open project refused

  • One short line under the buttons; nothing on disk changes. The lines, by case:
  • "No project in this folder" · "This project can't be opened" · "Made with a newer app version. Update to open it." · "This folder is inside Hawaii Photos" · "Pick a folder on this phone or its SD card".
  • Picking a project that is already listed just switches to it; no second row appears.
