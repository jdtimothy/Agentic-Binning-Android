Where the secondary filters go

Three ways to place the photo/video, shot type and date filters on Project Media. Everything else on the screen is the same as the approved mockup. Each phone is live: tap the filters and watch the grid and the result count change.

Decided Nov 2, 2026: option C, with the button labelled Filters instead of "More" (owner's choice).

OPTION A

A row of three dropdown chips, always visible

  • As in the approved Project Media mockup: "Photos and videos", "Any shot type", "Any date" under the category chips.
  • Each opens a small sheet with counts; a set filter turns blue and shows its value.
  • Every filter is always in view, so it's obvious when one is narrowing the grid.

OPTION B

One Filters button

  • A Filters button on the result line, next to Select, opens one sheet with all three groups.
  • With nothing set, the grid starts one row higher.
  • Set filters appear as blue chips with × under the category chips, and the button shows a count, so a narrowed grid is still visible.

OPTION C · chosen Nov 2

Type toggle, the rest behind Filters

  • An All · Photos · Videos toggle is always visible: "videos only" is one tap.
  • Filters opens a sheet for shot type and date; once set they show as blue chips beside the toggle.
  • Same height as A, with the most common filter fastest.
